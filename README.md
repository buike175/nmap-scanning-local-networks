# Network Discovery and Analysis with Nmap

> A hands-on networking and cybersecurity lab focused on discovering devices on an authorised local network, observing network information, and documenting findings with Nmap.

## Project overview

This project documents practical work with **Nmap** to explore how devices on a local network can be discovered and how scan results can be reviewed and analysed.

The goal is to build foundational skills in network visibility, network troubleshooting, and responsible security assessment.

## Objectives

- Understand the purpose of network discovery and port-scanning tools.
- Identify devices on a local network in an authorised lab environment.
- Review and interpret scan output.
- Record observations in clear, reproducible documentation.
- Practise responsible scanning and communicate findings professionally.

## Methodology

1. Define the authorised lab network and the assessment scope.
2. Confirm permission before scanning any device or network.
3. Use a basic Nmap host-discovery scan within the approved scope.
4. Review the results and note relevant observations.
5. Document the environment, date, limitations, and findings.
6. Remove or redact private addresses, hostnames, and other sensitive details before publishing evidence.

See [Methodology](documentation/methodology.md) for the documentation workflow.

## Responsible use

This project is for learning and authorised lab work only. Scan only networks and devices you own or have explicit permission to assess. Do not publish other people's IP addresses, device names, scan output, or network details without permission.
