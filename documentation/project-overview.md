# Project Overview

## Title
Network Discovery and Analysis with Nmap

## Summary
This project records practical learning in local-network discovery and analysis using Nmap. It is intended to demonstrate foundational networking knowledge, careful handling of scan results, and clear technical documentation.

## Learning goals
- Understand how devices participate in a local network.
- Learn what network discovery can reveal.
- Become familiar with Nmap output.
- Practise recording observations and limitations.
- Follow an authorised, non-disruptive lab process.

## Scope
The work is limited to a local lab network or another environment for which explicit permission has been granted. The published repository should contain only sanitised examples and evidence.

## Current status
The repository owner reports having scanned, observed, and analysed networks. Detailed environment information and verified findings have not yet been added. This document intentionally avoids inventing scan results.
