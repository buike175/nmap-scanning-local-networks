# Tools and Technologies

## Nmap
Nmap (Network Mapper) is a network exploration tool used by administrators and security practitioners to learn about hosts and services on networks.

**Role in this project:** basic discovery of devices in an authorised local lab and review of the resulting output.

Official documentation: https://nmap.org/book/man.html
